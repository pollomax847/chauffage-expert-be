# Documentation Chauffage Expert

## 1. Configuration et Préférences

### 1.1 Marges de Calcul
- **Chauffage** : Coefficient multiplicateur (1.0 - 2.0) pour ajuster la puissance calculée
- **ECS** : Coefficient multiplicateur (1.0 - 2.0) pour le dimensionnement des installations
- **VMC** : Coefficient multiplicateur (1.0 - 2.0) pour le calcul des débits

### 1.2 Unités de Mesure
- **Température**
  - °C (Celsius)
  - °F (Fahrenheit)
  - K (Kelvin)
- **Puissance**
  - W (Watt)
  - kW (Kilowatt)
  - BTU/h (British Thermal Unit per hour)
- **Débit**
  - m³/h (mètres cubes par heure)
  - L/s (litres par seconde)
  - CFM (Cubic Feet per Minute)

### 1.3 Apparence
- **Thème**
  - Système : suit les paramètres du système d'exploitation
  - Clair : thème clair optimisé pour la lecture
  - Sombre : thème sombre pour réduire la fatigue oculaire
- **Taille de Police**
  - Ajustement de 0.8x à 1.2x de la taille par défaut
  - Application immédiate dans toute l'interface
- **Langue**
  - Français (par défaut)
  - Anglais

### 1.4 Calculs
- **Précision**
  - Nombre de décimales : 0 à 4
  - Application aux résultats et affichages
- **Format des Nombres**
  - Point décimal (1.234)
  - Virgule décimale (1,234)
- **Arrondi**
  - Automatique selon la précision définie
  - Application aux calculs intermédiaires
