# Guide d'Utilisation

## Installation

1. Cloner le dépôt :
```bash
git clone https://github.com/votre-username/chauffage_expert.git
cd chauffage_expert
```

2. Installer les dépendances :
```bash
flutter pub get
```

3. Lancer l'application :
```bash
flutter run
```

## Premiers Pas

### Création d'un Client
1. Cliquez sur "Clients" depuis l'écran d'accueil
2. Appuyez sur le bouton "+" en bas à droite
3. Remplissez les informations du client :
   - Nom
   - Prénom
   - Adresse
   - Téléphone
   - Email
4. Validez avec "Enregistrer"

### Création d'une Étude
1. Sélectionnez un client dans la liste
2. Appuyez sur "Nouvelle Étude"
3. Remplissez les informations :
   - Adresse de l'étude
   - Surface
   - Hauteur sous plafond
   - Température souhaitée
4. Validez avec "Créer"

## Calculs

### Calcul Automatique
1. Les calculs sont effectués automatiquement dès que vous changez une valeur
2. Les résultats s'affichent en temps réel
3. Les alertes apparaissent si nécessaire

### Paramètres de Calcul
1. Accédez aux "Préférences" depuis le menu
2. Ajustez les coefficients selon vos besoins
3. Les calculs se mettent à jour automatiquement

## Export

### Génération du Rapport
1. Cliquez sur "Générer Rapport" depuis une étude
2. Vérifiez les informations à inclure
3. Cliquez sur "Exporter"

### Formats Disponibles
- PDF
- Excel
- Partage direct par email

## Préférences

### Unités de mesure
- Température (°C/°F)
- Puissance (kW/HP)
- Débit (m³/h/CFM)

### Marges de calcul
- Chauffage : 1.2 (par défaut)
- ECS : 1.3 (par défaut)
- VMC : 1.1 (par défaut)

### Apparence
- Thème clair/sombre
- Taille de police
- Langue

## Dépannage

### Problèmes Courants
- Vérifiez que toutes les données sont correctement saisies
- Redémarrez l'application en cas de comportement inattendu
- Mettez à jour l'application vers la dernière version
