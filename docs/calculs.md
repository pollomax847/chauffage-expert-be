# Calculs Techniques

## Débit

Le débit est calculé selon la formule :

```
Q = K × Σ(Puissance)
```

Où :
- Q : Débit en L/s
- K : Coefficient de simultanéité
- Puissance : Puissance de chaque radiateur en kW

## Coefficient de Simultanéité

Le coefficient de simultanéité est calculé selon la norme DTU 60.11 :

```
K = 0.7 × (1 - 1/n)
```

Où n est le nombre de radiateurs.

## Diamètre des Tuyaux

Le diamètre intérieur est calculé selon la formule :

```
D = √(4 × Q / (π × v))
```

Où :
- D : Diamètre intérieur en mm
- Q : Débit en L/s
- v : Vitesse maximale (1.5 m/s)

## Vitesse d'Écoulement

La vitesse est vérifiée selon la formule :

```
v = 4 × Q / (π × D²)
```

La vitesse doit être inférieure à 1.5 m/s.
