# Guide d'Utilisation

## Installation

1. Cloner le dépôt
2. Installer les dépendances : `flutter pub get`
3. Lancer l'application : `flutter run`

## Gestion des Clients

### Création d'un Client
1. Cliquer sur le bouton "+" en bas à droite
2. Remplir les informations du client
3. Valider

### Modification d'un Client
1. Sélectionner un client dans la liste
2. Modifier les informations
3. Valider

## Études Thermiques

### Création d'une Étude
1. Sélectionner un client
2. Cliquer sur "Nouvelle étude"
3. Remplir les informations de l'étude
4. Valider

### Calcul des Débits
1. Sélectionner une étude
2. Remplir les informations des radiateurs
3. Le calcul est effectué automatiquement

## Génération de PDF

1. Sélectionner une étude
2. Cliquer sur "Générer PDF"
3. Le rapport est généré et peut être partagé
