## Installation

1. Téléchargez l'application depuis le Play Store ou l'App Store
2. Lancez l'application
3. Acceptez les permissions nécessaires
4. Créez un compte ou connectez-vous

## Premiers pas

L'interface principale se compose de :
- Menu de navigation
- Barre de recherche
- Liste des projets récents
- Bouton de création de nouveau projet

## Calculs de chauffage

1. Accédez à la section "Chauffage"
2. Entrez les paramètres :
   - Surface du logement
   - Hauteur sous plafond
   - Coefficient d'isolation
3. Cliquez sur "Calculer"
4. Consultez les résultats :
   - Puissance nécessaire
   - Type de générateur recommandé
   - Surface totale

## Calculs ECS

1. Accédez à la section "ECS"
2. Renseignez :
   - Nombre de logements
   - Nombre d'étages
   - Nombre de points d'eau
3. Validez pour obtenir :
   - Débit total
   - Diamètre recommandé
   - Coefficient de simultanéité

## Calculs VMC

1. Ouvrez la section "VMC"
2. Saisissez :
   - Type de VMC (simple/double flux)
   - Nombre de logements
   - Taux d'occupation
   - Détails des locaux
3. Calculez pour voir :
   - Débit total
   - Pertes de charge
   - Puissance du ventilateur

## Calculs collectifs

### Chaudière collective
1. Accédez à "Collectif > Chaudière"
2. Entrez :
   - Nombre de logements
   - Surface chauffée
   - Niveau d'isolation
   - Températures intérieure/extérieure
3. Obtenez :
   - Puissance de base
   - Coefficient température
   - Puissance totale recommandée

### Pompes de circulation
1. Allez dans "Collectif > Pompes"
2. Renseignez :
   - Débit volumique
   - Hauteur manométrique
   - Longueur du réseau
   - Pertes linéaires
3. Consultez :
   - Pertes de charge
   - Puissance hydraulique
   - Vitesse de rotation

## Géothermie

1. Ouvrez "Géothermie"
2. Saisissez :
   - Puissance thermique
   - Température source
   - Température émise
   - Profondeur
3. Obtenez :
   - Nombre de sondes
   - Longueur totale
   - Espacement entre sondes
   - Surface au sol

## Génération de rapports

1. Accédez à "Rapports"
2. Sélectionnez le type de rapport
3. Choisissez les données à inclure
4. Cliquez sur "Générer PDF"
5. Partagez ou sauvegardez le rapport

## Gestion des données

1. Accédez à "Données"
2. Options disponibles :
   - Sauvegarder les données
   - Charger des données
   - Supprimer des données
   - Consulter l'historique
