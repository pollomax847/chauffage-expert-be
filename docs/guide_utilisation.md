# Guide d'Utilisation

## Installation
1. Téléchargez l'application depuis le Play Store/App Store
2. Lancez l'application
3. Acceptez les permissions nécessaires

## Premiers Pas

### Création d'un Client
1. Cliquez sur "Nouveau Client"
2. Remplissez les informations :
   - Nom
   - Prénom
   - Adresse
   - Téléphone
   - Email
3. Sauvegardez

### Création d'une Étude
1. Sélectionnez un client
2. Cliquez sur "Nouvelle Étude"
3. Remplissez les informations :
   - Adresse de l'étude
   - Surface
   - Hauteur sous plafond
   - Température souhaitée
4. Sauvegardez

### Ajout de Radiateurs
1. Ouvrez une étude
2. Cliquez sur "Ajouter Radiateur"
3. Remplissez les caractéristiques :
   - Référence
   - Modèle
   - Dimensions
   - Puissance
   - Matériau des tuyaux
4. Sauvegardez

## Calculs

### Calcul Automatique
1. Les calculs sont effectués automatiquement
2. Les résultats s'affichent en temps réel
3. Les alertes apparaissent si nécessaire

### Paramètres de Calcul
1. Accédez aux paramètres
2. Ajustez les coefficients si nécessaire
3. Les calculs se mettent à jour automatiquement

## Export

### Génération du Rapport
1. Cliquez sur "Générer Rapport"
2. Vérifiez les informations
3. Cliquez sur "Exporter"

### Formats Disponibles
- PDF
- Excel
- Partage direct

## Fonctionnalités Avancées

### Historique
- Consultation des anciennes études
- Comparaison des résultats
- Tendances d'évolution

### Statistiques
- Tableaux de bord
- Graphiques
- Rapports personnalisés

## Dépannage

### Problèmes Courants
- Calculs incorrects
- Données manquantes
- Erreurs d'export

### Solutions
1. Vérifiez les données saisies
2. Mettez à jour l'application
3. Contactez le support
